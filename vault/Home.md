# PickleMatch

PickleMatch is an app to find and join pickleball games.

## Stack

- Backend: Laravel (`backend/`)
- Frontend: React + Vite + Tailwind v4 + react-router (`frontend/`)
- Database: Postgres
- Dev environment: Docker Compose (`docker-compose.yml`)
